# Security policy

This plugin enforces a read-only sandbox and a boundary on what leaves the machine, so a bug in it is a security bug for whoever installed it.

**Please report vulnerabilities privately:** [open a private security advisory](https://github.com/ujconsulting/claudex-loop/security/advisories/new) (GitHub's private vulnerability reporting), or write to **security@ujconsulting.info**. Only the latest version on `main` is supported.
